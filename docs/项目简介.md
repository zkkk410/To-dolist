# 项目简介

## GitHub About 简介

Windows 桌面胶囊待办：多清单、截止倒计时、钉住穿透、自由缩放、本地 JSON 存储。参考 PaperTodo，在 AI 辅助下完成的个人学习仿改项目。

## 简短介绍

To-dolist 是一款 Windows 桌面待办小工具，把工作和生活事项放进可自由移动、缩放的胶囊窗口。支持截止日期、剩余时间、提醒、归档和鼠标穿透，单文件 EXE 双击运行，数据保存在旁边的 data.json，无需注册账号。
