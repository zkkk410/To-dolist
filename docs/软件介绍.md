# To-dolist｜轻量桌面胶囊待办

![To-dolist 概览示意图](images/overview.svg)

## 把清单留在看得见的地方

To-dolist 将待办分成一个个独立的桌面胶囊。工作安排、生活计划、临时事项可以分别放在不同清单里，不需要一直打开一个大窗口。

它采用暖色纸张风格：细边框、紧凑标题栏、小号文字和柔和的棕金色提示，让内容保持清楚，也尽量少占桌面空间。

## 输入、设日期，回车保存

![待办编辑与截止信息实机截图](images/work-capsule.png)

在底部输入文字，右侧会出现时间图标。需要截止日期时，点开内置日历，先调整时、分，再点击日期，面板会自动保存并收起。最后回车，将条目和日期一起加入清单。

设置日期后，条目下面同时显示两类信息：

- **还有多久截止**：以天、小时、分钟展示，自动刷新。
- **具体什么时候截止**：完整日期和时间，方便核对。

到期后改为显示逾期时长。程序还支持提前提醒，提醒功能需要应用保持运行，并受 Windows 通知设置影响。

## 钉住时只看，需要时再编辑

![钉住后的清单实机截图](images/pinned-capsule.png)

点左上角的钉住按钮，胶囊进入锁定状态，清单主体区域鼠标穿透；标题、条目和关闭按钮不再接受编辑或点击。取消钉住按钮由独立的小窗口接收点击，方便恢复操作。

取消钉住后，胶囊恢复完全不透明，便于录入和修改。再次钉住时恢复托盘中设置的透明度。

> “钉住”指固定位置、锁定内容并开启穿透，不等于“始终置顶”。需要显示在其他窗口上方时，可另外启用托盘菜单中的置顶选项。

## 清单怎么摆，由你决定

取消钉住后，拖动标题旁的 `⠿` 调整位置，拖动窗口边缘或角落调整大小。布局会自动保存；手动设置的尺寸不会被内容自动高度覆盖，也可从右键菜单恢复自动高度。

完成的待办勾选后进入归档；需要继续处理时，可以从菜单恢复。右上角 `×` 只是隐藏胶囊。如果确定不要整个清单，可从右键菜单删除，程序会先让你确认。

## 一个 EXE，一个数据文件

```text
双击 To-dolist.exe
        ↓
桌面胶囊 + 托盘菜单
        ↓
同目录 data.json 自动保存
```

程序不需要登录账号。使用单文件便携版时，运行组件会自动展开到本机缓存，而待办数据仍留在 EXE 旁边。换电脑时一起复制 EXE 和 JSON 即可。

这些截图使用演示清单；并非个人真实任务。字体为 Arial 与 Noto Sans SC，后者未安装时会回退到系统中文字体。
